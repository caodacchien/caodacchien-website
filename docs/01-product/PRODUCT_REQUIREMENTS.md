# Product Requirements Document

## 1. Tổng quan

Sản phẩm là website thương hiệu cá nhân của Cao Đắc Chiến, phục vụ đồng thời mục tiêu nghề nghiệp, học thuật và chia sẻ kiến thức.

## 2. Đối tượng chính

1. Nhà tuyển dụng và Hiring Manager
2. Khách hàng và đối tác
3. Đồng nghiệp trong ngành
4. Sinh viên/người mới
5. Hội đồng tuyển sinh
6. Thành viên cộng đồng

## 3. Giá trị cốt lõi

Website phải giúp người xem nhanh chóng trả lời:
- Cao Đắc Chiến là ai?
- Có kinh nghiệm gì?
- Đã tạo ra kết quả gì?
- Có năng lực chuyên môn nào?
- Có thể liên hệ hoặc hợp tác bằng cách nào?

## 4. Kiến trúc thông tin

- Home
- About
- Experience
- Projects
- Blog
- Resources
- Speaking / Teaching
- Contact

## 5. Yêu cầu chức năng MVP

### Home
- Hero rõ định vị
- Featured projects
- Latest posts
- Career highlights
- CTA liên hệ

### About
- Biography
- Core values
- Skills
- Education
- Certifications
- Timeline

### Experience
- Company
- Role
- Period
- Responsibilities
- Quantified impact
- Related projects

### Projects
- List và filter
- Case study
- Problem / Solution / Result
- Gallery
- Tech stack
- Demo / GitHub nếu có

### Blog
- Categories
- Tags
- Search
- Reading time
- Table of contents
- Related posts
- SEO metadata

### Contact
- Contact form
- Social links
- Email
- Optional calendar booking

## 6. Yêu cầu phi chức năng

- Responsive
- Accessible
- Lighthouse mục tiêu từ 90 trở lên cho Performance, SEO, Accessibility trong điều kiện hợp lý
- Core Web Vitals tốt
- Metadata đầy đủ
- Không phụ thuộc JavaScript cho nội dung SEO chính
- Có error state, loading state và empty state

## 7. Nội dung cần bổ sung trước khi code

- Positioning statement
- Ảnh chân dung
- Bio ngắn và dài
- Danh sách kinh nghiệm
- Danh sách project
- Hồ sơ học vấn
- Chứng chỉ
- Social links
- Contact email
- Ngôn ngữ website: Việt, Anh hay song ngữ

## 8. Success Metrics

- Hoàn thành MVP
- Index trên Google
- Form liên hệ hoạt động
- Tăng số lượt xem portfolio/blog
- Có ít nhất 3 case study chất lượng
- Có quy trình xuất bản nội dung ổn định
